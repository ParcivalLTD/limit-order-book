# A limit order book and a market maker that loses money

A matching engine, a naive market maker, and the order flow that trades against
it. I am building this to find out what actually happens to a quoting strategy
when some of the people hitting it know more than it does, because I have read
the words "adverse selection" several times without having any feel for the size
of the effect.
